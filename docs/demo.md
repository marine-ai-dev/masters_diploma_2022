# Demo recordings

The original project includes screen recordings demonstrating the working web application
and database. These are multi-gigabyte `.mov` files and are intentionally **not** committed
to this repository (see `docs/artefact-index.md` for the size policy).

They remain available in the original Google Drive source archive:

- Web application demo: `15_videozapys_roboty_web-dodatku/` (folder in the source Drive archive)
- Database demo: `16_videozapys_roboty_bazy_danykh/` (folder in the source Drive archive)

The repository owner retains access to the source Drive folder these were exported from.
